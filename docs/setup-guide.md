# 導入手順書：Google フォームの回答から書類を自動作成・送信

この手順書の通りに進めると、Google フォームに回答が届くたびに、次の処理が自動で行われるようになります。

1. 回答の内容を書類（Google ドキュメント）に差し込み、PDF にする
2. PDF を Google ドライブのフォルダに保存する
3. 回答者に PDF を添付したメールを送る
4. 担当者に通知メールを送る（任意）
5. 処理の結果をスプレッドシートに記録する

プログラミングの知識は必要ありません。所要時間は 30 分ほどです。

---

## 準備するもの

- Google アカウント（無料のアカウントでも、Google Workspace でも使えます）
- パソコンのブラウザ（Google Chrome を推奨）
- 導入担当者から受け取った「テンプレートのスプレッドシート」のリンク

> **1 日に送れるメールの数には上限があります。** 無料の Google アカウントは少なめ、Google Workspace は多めです。1 件の回答につき最大 2 通（回答者宛と担当者宛）を使います。回答が多い場合は Google Workspace のアカウントで導入してください。

---

## 手順 1：スプレッドシートをコピーする

1. 導入担当者から受け取ったリンクを開きます。
2. メニューの「ファイル」→「コピーを作成」を選びます。
3. 名前を付けて（例：「見積依頼の自動送信」）、「コピーを作成」を押します。

以降は、**コピーしたスプレッドシート** を使います。

---

## 近道：サンプルから始める（おすすめ）

用途が次のどれかに近い場合は、サンプルを作成すると、フォーム・書類のテンプレート・設定が一度に揃い、手順 2〜7 を省略できます。

| サンプル | 使い方 |
|---|---|
| 見積書（社内用） | 担当者がフォームにお客様の情報と金額を入力すると、お客様に見積書が届く |
| 申込控え（講座の申し込み） | お客様がフォームで申し込むと、申し込み内容の控えが届く |
| 受講証明書（社内用） | 担当者がフォームに受講者と講座の情報を入力すると、受講者に受講証明書が届く |

1. コピーしたスプレッドシートを開き、メニューに「**書類の自動送信**」が表示されるまで数秒待ちます。
2. 「書類の自動送信」→「**サンプルを作成**」→ 使いたいサンプルを選びます。
3. 初回は「承認が必要です」と表示されるので、[手順 5 の 4](#手順-5初期設定を実行する1-回目設定シートを作る) と同じように承認し、もう一度 2 を実行します。
4. 確認の画面で「はい」を押すと、スプレッドシートと同じ場所に「（サンプル名）サンプル」フォルダができ、フォーム・書類のテンプレート・PDF の保存先フォルダが作られます。「設定」シートも自動で入力されます。
5. メニューの「フォーム」→「ライブフォームに移動」でフォームを開き、**自分のメールアドレスで** 回答して送信します。
6. 届いたメールと「PDF」フォルダの書類を確認します。
7. 書類のテンプレート（「【テンプレート】〇〇」という名前のドキュメント）を開き、「株式会社サンプル（← 書き換えてください）」などを自社の情報に書き換えます。メール本文は「設定」シートの「本文テンプレート」で書き換えられます。

フォームの質問は自由に追加・変更できます。質問のタイトルを変えた場合は、テンプレートの `{{ }}` も合わせて直してください（[差し込みの書き方](#差し込みの書き方)）。

> すでにフォームがリンクされているスプレッドシートでは、サンプルを作成できません。

サンプルを使わずに自分で作る場合は、手順 2 に進んでください。

---

## 手順 2：Google フォームを作り、スプレッドシートにリンクする

すでにフォームがある場合は、2 から進めてください。

1. <https://forms.google.com> を開き、「空白のフォーム」から質問を作ります。
   - 例：「お名前」「会社名」「合計金額」「メールアドレス」
   - **質問のタイトルは、あとで書類に差し込むときの名前になります。** 短く、分かりやすい名前にしておくと便利です。
2. 回答者のメールアドレスは、次のどちらかの方法で集めます。
   - **A. 質問として聞く**：「メールアドレス」という記述式の質問を作る（回答の検証で「メールアドレス」を選ぶと入力ミスを防げます）
   - **B. 自動で集める**：フォームの「設定」タブ →「回答」→「メールアドレスを収集する」を「確認済み」にする
3. フォームの「回答」タブを開き、「スプレッドシートにリンク」を押します。
4. 「既存のスプレッドシートを選択」を選び、**手順 1 でコピーしたスプレッドシート** を選びます。

スプレッドシートに「フォームの回答 1」というシートが増えていれば成功です。

---

## 手順 3：書類のテンプレートを作る

1. <https://docs.google.com> で新しいドキュメントを作り、書類のひな形を作ります。
2. 回答を差し込みたい場所に、`{{質問のタイトル}}` と書きます。

```
{{会社名}} 御中
{{お名前}} 様

お見積金額：{{合計金額:yen}}
発行日：{{今日}}
```

これで、`{{会社名}}` の部分がフォームの「会社名」の回答に置き換わります。ヘッダー・フッター・表の中にも書けます。

### 差し込みの書き方

| 書き方 | 回答の例 | 書類での表示 |
|---|---|---|
| `{{お名前}}` | 山田 太郎 | 山田 太郎 |
| `{{合計金額:yen}}` | 12000 | ¥12,000 |
| `{{数量:number}}` | 1500 | 1,500 |
| `{{希望日:date(yyyy/MM/dd)}}` | 2026-10-15 | 2026/10/15 |
| `{{希望日:date(M月d日(E))}}` | 2026-10-15 | 10月15日(木) |
| `{{今日}}` | ―（処理した日） | 2026年10月2日 |
| `{{送信日時}}` | ―（フォームが送信された日時） | 2026年10月2日 14:58 |

- チェックボックスの回答は「印刷、製本」のように「、」でつないで差し込みます。
- 日付の形式で使える記号：`yyyy`（年）・`MM` / `M`（月）・`dd` / `d`（日）・`HH` / `H`（時）・`mm`（分）・`E`（曜日）
- `{{ }}` の中は、フォームの質問のタイトルと **一字一句同じ** にしてください。違っていると、エラーとして処理が止まり、担当者に知らせが届きます。
- 回答が空の質問（任意の質問など）は、空欄で差し込まれます。

---

## 手順 4：PDF の保存先フォルダを作る

1. <https://drive.google.com> を開き、「新規」→「新しいフォルダ」で保存先フォルダを作ります（例：「見積書PDF」）。

> **個人情報の取り扱いに注意してください。** PDF にはフォームの回答（氏名・連絡先など）が含まれます。フォルダとスプレッドシートは、必要な人だけに共有してください。

---

## 手順 5：初期設定を実行する（1 回目：「設定」シートを作る）

1. コピーしたスプレッドシートを開き直します。
2. メニューに「**書類の自動送信**」が表示されるまで、数秒待ちます。
3. 「書類の自動送信」→「**初期設定**」を押します。
4. 初回は「承認が必要です」と表示されるので、次のように進みます。
   1. 「続行」を押す
   2. 自分の Google アカウントを選ぶ
   3. 「このアプリは Google で確認されていません」と表示されたら、左下の「**詳細**」→「**（プロジェクト名）（安全ではないページ）に移動**」を押す
   4. 内容を確認して「**許可**」を押す

   > この警告は、Google の審査を受けていない自作のスクリプトに必ず表示されるものです。このスクリプトは、あなたのアカウントの中だけで動きます。

5. 承認が終わったら、もう一度「書類の自動送信」→「初期設定」を押します。
6. 「「設定」シートを作成しました」と表示され、「設定」シートが追加されます。

---

## 手順 6：「設定」シートを入力する

「設定」シートの **B 列** に値を入力します。各項目の説明は C 列にもあります。

| 項目（A 列） | 入力する値（B 列） |
|---|---|
| テンプレートのドキュメントID | 手順 3 のドキュメントの URL をそのまま貼り付け |
| 保存先フォルダID | 手順 4 のフォルダの URL をそのまま貼り付け |
| ファイル名テンプレート | 例：`見積書_{{会社名}}_{{今日:date(yyyyMMdd)}}` |
| 回答者のメールアドレスの項目名 | 手順 2 の **A** の場合：質問のタイトル（例：`メールアドレス`）／ **B** の場合：空欄 |
| 件名テンプレート | 例：`{{お名前}} 様 お見積書を送付します` |
| 本文テンプレート | メールの本文。`{{ }}` も使えます。セル内の改行は Alt+Enter（Mac は ⌘+Enter） |
| 担当者のメールアドレス | 送信の通知とエラーを受け取るアドレス（任意）。複数ある場合は `,` で区切る |

本文テンプレートの例：

```
{{お名前}} 様

このたびはお見積りのご依頼をいただき、ありがとうございます。
お見積書を添付いたしますので、ご確認ください。

山田商店
```

- A 列の項目名は変更しないでください。

---

## 手順 7：初期設定を実行する（2 回目：自動処理を有効にする）

1. 「書類の自動送信」→「**初期設定**」を押します。
2. 「**初期設定が完了しました**」と表示されれば成功です。

設定に不備があると「設定に不備があります」と表示され、どの行の何を直せばよいかが表示されます。直してから、もう一度「初期設定」を押してください。

---

## 手順 8：テスト送信で確認する

1. フォームの右上の「プレビュー」（目のアイコン）から、テスト用の回答を 1 件送信します。
   - この時点で自動処理が動き、回答で入力したメールアドレスに書類が送られます。**自分のメールアドレスで回答** してください。
2. 「書類の自動送信」→「**テスト送信**」を押すと、最新の回答で書類を作り直し、**あなた宛に** 送信します（回答者には送られません）。
3. 届いたメールと、保存先フォルダの PDF（ファイル名の先頭に「テスト_」が付きます）を確認します。
   - 書類やメールの内容を直したい場合は、テンプレートのドキュメントや「設定」シートを修正し、もう一度「テスト送信」を押します。
   - 確認が終わったら、テスト用の PDF は削除して構いません。

これで導入は完了です。

## 日々の運用

### 結果の確認（「記録」シート）

回答を処理するたびに、「記録」シートに 1 行追加されます。

| 処理日時 | 回答ID | 回答者 | PDFのURL | 結果 | エラー内容 |
|---|---|---|---|---|---|

「結果」は次のいずれかです。

- **成功**：書類を作成し、回答者に送信しました
- **失敗**：何らかの理由で送信できませんでした（理由は「エラー内容」に表示されます）
- **再送済み**：失敗した行を再送しました（再送の結果は、下に追加された行に表示されます）

### 失敗したときは

失敗すると、担当者（設定していなければスクリプトの所有者）にエラー内容のメールが届きます。

1. エラー内容を読み、テンプレートや「設定」シートを直します。
2. 「書類の自動送信」→「**失敗分を再送**」を押します。
3. 確認の画面で「はい」を押すと、「失敗」の回答をもう一度処理して送信します。

1 回に再送できるのは 20 件までです。残りがある場合は、もう一度「失敗分を再送」を押してください。

### よくあるエラー

| エラー内容 | 対処 |
|---|---|
| フォームに「○○」という質問が見つかりません | `{{ }}` の中や「回答者のメールアドレスの項目名」が、フォームの質問のタイトルと一致しているか確認する |
| 回答が数値ではないため yen の書式を使えません | 金額の質問の回答に数字以外が入っていないか確認する（フォームの「回答の検証」で数値に限定すると防げます） |
| 回答者のメールアドレスを取得できませんでした | 手順 2 の A または B の設定と、「回答者のメールアドレスの項目名」を確認する |
| テンプレートのドキュメントを開けませんでした | ドキュメントの URL と、自分のアカウントで開けるかを確認する |
| PDFの作成に失敗しました | フォルダの URL と、自分のアカウントでファイルを追加できるかを確認する |
| 回答者へのメール送信に失敗しました | 1 日の送信数の上限に達した可能性があります。時間をおいて「失敗分を再送」を押す |

### メール送信数の上限が近いとき

その日に送れるメールが残り 10 通を切ると、担当者に注意のメールが届きます（1 日 1 回）。上限は、およそ 24 時間で回復します。

### フォームを変更したとき

- 質問のタイトルを変えた場合は、テンプレートと「設定」シートの `{{ }}` も合わせて直してください。
- 別のフォームに切り替えた場合は、新しいフォームをスプレッドシートにリンクしてから、もう一度「初期設定」を押してください。
