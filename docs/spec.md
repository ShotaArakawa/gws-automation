# gws-automation 仕様書（MVP）

## 1. 目的
- 中小企業・教室・個人事業主が Google フォームで受けた申込や依頼に対して、書類作成とメール返信を手作業でやっている手間をなくす。
- 例：見積依頼 → 見積書 PDF、講座申込 → 申込控え PDF、修了 → 受講証明書 PDF
- 位置づけ：ポートフォリオ兼、副業（導入代行）の商材。将来は Google Workspace Marketplace のアドオン化。

## 2. 想定ユーザー
| ユーザー | 説明 |
|---|---|
| 導入担当者（非エンジニア） | テンプレートをコピーし、設定シートを埋めるだけで使い始める |
| フォーム回答者 | 送信後に PDF 付きのメールを受け取る |

## 3. MVP の機能

### 3.1 自動処理（フォーム送信時）
1. インストール型トリガー `onFormSubmit` で回答を受け取る
2. 設定に従い、Google ドキュメントのテンプレートをコピーして `{{項目名}}` を回答で置換
   - 日付・金額のフォーマット（例：`{{合計金額:yen}}` → ¥12,000）
3. PDF に変換し、指定の Drive フォルダに保存（ファイル名もテンプレートで指定可能）
4. メール送信
   - 回答者宛：件名・本文テンプレート＋PDF 添付
   - 担当者宛：通知（任意）
5. 記録シートに 1 行追加：日時、回答者、PDF の URL、送信結果（成功 / 失敗）、エラー内容

### 3.2 設定シート（「設定」）
| 項目 | 例 |
|---|---|
| テンプレートのドキュメント ID | 1AbC... |
| 保存先フォルダ ID | 1XyZ... |
| ファイル名テンプレート | 見積書_{{会社名}}_{{日付}} |
| 回答者のメールアドレスの項目名 | メールアドレス |
| 件名テンプレート / 本文テンプレート | {{お名前}} 様 お見積書を送付します |
| 担当者のメールアドレス | 任意 |

- 起動時に設定を検証し、不備があれば分かりやすい日本語のエラーを出す。

### 3.3 スプレッドシートのカスタムメニュー
- 「初期設定」：トリガーの作成、必要な権限の承認
- 「テスト送信」：最新の回答 1 件で PDF を作って自分宛に送る
- 「失敗分を再送」：記録シートで失敗になっている行を再処理

### 3.4 MVP に含めないもの（フェーズ2以降）
- Google Workspace アドオン化（CardService の UI、Marketplace 公開。公開には OAuth の審査が必要）
- 1 つのスプレッドシートで複数フォーム・複数テンプレートを扱う
- 電子署名、請求書番号の自動採番

## 4. 制約・注意点
- GAS の 1 回の実行は最大 6 分。1 回答あたりの処理は数秒に収める。
- メール送信数には 1 日の上限がある（無料の Google アカウントは少なく、Workspace は多い）。上限に近づいたら担当者に通知する。
- フォーム回答には個人情報が含まれるため、ログに出さない・必要な人だけがシートと Drive フォルダにアクセスできるようにする。

## 5. マイルストーン
| # | 内容 | 完了の目安 |
|---|---|---|
| M0 | TypeScript + esbuild + clasp の土台、Vitest、Biome、GitHub Actions | `pnpm build` → `clasp push` でスクリプトが更新される |
| M1 | 差し込みロジック（core）と単体テスト、設定シートの読み込みと検証 | テストが通る |
| M2 | フォーム送信 → PDF 作成 → メール送信 → 記録 | 実際のフォームで一連の処理が動く |
| M3 | カスタムメニュー（初期設定・テスト送信・再送）、導入手順書 | 非エンジニアが手順書だけで導入できる |
| M4 | ユースケース別テンプレート 3 種（見積書・申込控え・受講証明書） | ココナラに出品できる状態 |
| M5 | Workspace アドオン化の検討・試作 | — |

## 6. 売り出し方（メモ）
- 「Google フォームの回答から書類を自動作成・送信」の導入代行としてココナラ等で出品
- 汎用テンプレートを無料公開し、ブログ / X で導入事例を発信 → 有料の導入代行・カスタマイズへつなげる
